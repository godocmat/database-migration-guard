### Residual GitLab advisory

CVE-2026-103995 is a CVSS 4.0 **Low (2.0)** response-framing integrity issue in CPython `http.client`. The CLI image ships no Python. The affected GitLab image ships Wolfi `python-3.15-base` and `python-3.15-runtime` `3.15.2_git20261113-r0`, built from CPython `64b5cfdf7548a21741398ce0826728818327aea7`. The documented gate invokes Git for HTTPS and uses Python's URL parser and local data processing. Other use of the installed Python HTTP client still carries the package advisory. The split Wolfi packages did not automatically match CPython in the pinned Grype database. A supplemental upstream CPE lookup identified this residual after all eight original matches were addressed. [Python CNA record](https://cveawg.mitre.org/api/cve/CVE-2026-103995) · [Gate source](../../integrations/gitlab/gate.py) · [Exact scan scope](image-advisory-acceptance.md#exact-scans-and-upstream-cross-checks)

CPython merged the 3.15 backport `5b9e3d044764cf59329fb8147177f54a88d1fb49` on 18 November 2026. It is 47 commits ahead of the shipped Wolfi snapshot, and the public Wolfi recipe checked that day still used the earlier commit. The release owner can accept the documented risk for the pinned gate-only profile, rebuild with a verified patched Wolfi package and rerun image validation, or hold the GitLab image.
