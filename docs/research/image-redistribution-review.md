# Wolfi image redistribution review

This draft covers the Linux x86-64 images built from the Wolfi recipes at `32a8f15f54b59731bdc8cfe9376dfbaaa714cfcd` and the native Guard executable from `af21401`. The base is the Cosign-verified public Wolfi manifest `sha256:7b01dd2f4364d52e4c9ceaf149eb61e5510a41a3b178f230ef785e9bf26c6c4b`. The signed base SPDX attestation binds its source references to that digest. The Guard binary and its build inputs have a separate notice inventory. [Chainguard SPDX source references](https://www.chainguard.dev/docs/chainguard/containers/security-and-compliance/retrieve-image-sboms#license-information-and-source-code-references) · [Guard binary notice review](release-notices-review.md)

The installed APK databases extracted from both OCI archives matched all reviewed package names, versions and declared license expressions. The GitLab archive contained the reviewed Python and mpdecimal notice files and the exact pip wheel. The final reproducible Wolfi archives were checked again and match all 43 and 54 package records and the reviewed GitLab notice and wheel bytes. ## Retained files and release review

The follow-up matched the final OCI archives and package databases to the recorded digests. All 19 exact base APKs matched the installed APK database control checksums from the pinned image. All 35 additions matched the retained Wolfi snapshot, repository SHA-256 locks, and installed control checksums. Each control record also bound the APK payload by SHA-256. The review retained the build recipes and SPDX records for all 54 APKs across 45 source package groups. [Final image inventory](image-advisory-acceptance.md) · [Wolfi embedded build metadata](https://www.chainguard.dev/docs/platform/mcp-servers/cg-apk)

The review acquired all 44 upstream archives identified by those SPDX records. Thirty-one archive headers and eleven producer archive directory names matched the Git revisions in the authenticated recipes. The mpdecimal and SQLite archives matched the recipes' SHA-256 pins. The four configuration and metapackage groups with no separate upstream archive are `krb5-conf`, `wolfi-baselayout`, `wolfi-base`, and `wolfi-keys`. The draft retains the verified build recipes and relevant APK payloads for those groups. [Upstream archive index](wolfi-source-archives.json) · [Chainguard source retrieval](https://support.chainguard.dev/hc/en-us/articles/56768221947675-Download-the-source-code-for-packages-in-a-Chainguard-image)

Every one of the 36 distinct downstream files named by the embedded source checksum manifests matched its pinned SHA-256. The 22 newly verified files include the remaining Python patch, five bzip2 patches, two Kerberos patches, three glibc support files, and eleven Wolfi base layout inputs. BusyBox and other recipes without a source checksum manifest need review of their downstream inputs against the exact producer build.
