## Guard project license

The proposed revision has no project license file and no Cargo license or `license-file` fields for Guard. The public repository reports no detected license. The plan allows a project LICENSE or an approved decision record and discusses a permissive Community edition. The release owner still needs to confirm the relevant rightsholders and contributor permissions and approve the project license or distribution terms, including any boundaries between Community and commercial distribution. Record the decision before applying the terms to the checkout, Cargo manifests, package materials, and release notes. Approve the third-party notices and source-access terms for the actual packages and image digests alongside that decision.
